# حزمة استعادة مشاريع MK~2

ملف واحد لتسليمه إلى مطوّر أو ذكاء اصطناعي لإعادة بناء المشاريع وتشغيلها في بيئة جديدة.

**[تنزيل الحزمة الكاملة — ZIP، حوالي 33 MB](https://raw.githubusercontent.com/MANK51/BOTn/project-recovery-2026-11-06/MK2-projects-complete-2026-11-06.zip)**

- 12 مشروعًا بملفات المصدر المتاحة بتاريخ 6 نوفمبر 2026.
- 1,185 ملف مصدر، مع الصور والخطوط وملفات القفل والإعداد والمخططات والترحيلات والأصول المحفوظة.
- 119 تعديل Git أصليًا داخل 12 حزمة تاريخ مستقلة.
- دليل استعادة ومتطلبات تشغيل وتعريف بالخدمات المطلوبة لكل مشروع.

ابدأ بقراءة [START_HERE.md](START_HERE.md)، ثم أعط الذكاء الاصطناعي نص [AI_RESTORE_PROMPT.txt](AI_RESTORE_PROMPT.txt) والحزمة. يمكن تنزيل النص مباشرة من [هذا الرابط](https://raw.githubusercontent.com/MANK51/BOTn/project-recovery-2026-11-06/AI_RESTORE_PROMPT.txt).

بعد فك الضغط:

```sh
cd mk2-projects-recovery
python3 scripts/verify_integrity.py
```

[بصمة SHA-256 لملف ZIP](MK2-projects-complete-2026-11-06.zip.sha256). تحتوي الحزمة أيضًا على بصمات لجميع ملفاتها.

المشروعان آية ويدجت وكاشف API مسجلان لكن مستودعات مصادرهما فارغة، وتوجد صفحات توضح ذلك. أسرار الخدمات وسجلات قواعد الإنتاج وملفات التخزين المرفوعة أثناء التشغيل ليست في مستودعات المصدر. مصدر Getsup المتاح هو صفحة التحميل والإدارة، ولا يتضمن المصدر الخارجي للتطبيق المرتبط أو ملفات APK غير المحفوظة فيه.

هذا الفرع مخصص للتنزيل؛ فرع المستودع الأساسي مستقل عنه.
